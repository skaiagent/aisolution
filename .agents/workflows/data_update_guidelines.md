---
description: 데이터 업데이트 및 팩트체크 가이드라인
---
이 워크플로우는 AI 솔루션 대시보드의 데이터 무결성을 유지하기 위한 자동화/수동 검수 지침입니다. `data.json`을 업데이트할 때마다 반드시 이 지침을 준수해야 합니다.

1. **링크 유효성 전수 검사 (Link Health Check)**
    - `data.json`에 기재된 모든 `sources` 및 `link` URL에 대해 백엔드 HTTP 200 OK 상태를 점검합니다.
    - 접근 불가능(403, 404, Redirect 실패), SSL 오류 등이 발생하는 깨진 링크는 발견 즉시 최신 официальный(공식) URL로 교체하거나 삭제합니다.
    - 단 URL 호출 시 안티봇(Cloudflare 등)으로 인해 의도치 않게 HTTP 에러 코드를 리턴하는 정상 사이트는 예외 처리합니다.

2. **기능 템플릿 배제 및 고유 기능 팩트체크 (Feature Fact-checking)**
    - 임시로 기입된 템플릿형 기능 문구("AI 기반 자동화", "실시간 데이터 분석", "엔터프라이즈 보안", "다양한 서비스 연동" 등)의 사용을 금지합니다.
    - 솔루션별 기능(`features` 항목) 추가 또는 업데이트 시 웹 검색과 크로스 체크를 통해 해당 서비스만의 고유하고 기술적인 실제 기능으로 엄격히 팩트체크하여 반영해야 합니다.
    - 팩트 검증이 되지 않은 정보는 보류 상태로 남겨두고 "상세 정보 준비 중"으로 표기합니다.

3. **엔터프라이즈 및 보안 적합성**
    - 업데이트되는 솔루션이 On-premise(구축형), 폐쇄망 환경 지원, SSO/SAML 등의 엔터프라이즈 레벨 보안을 지원하는지 확인하여 `desc`, `features`에 반영합니다.
